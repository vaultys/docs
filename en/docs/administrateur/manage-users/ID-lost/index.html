A user has lost/broken their phone

In case of a lost or broken phone, you can associate a new Vaultys identity with your employee/user's account.

1. Click on the Users tab​

Access the user management page by clicking on the Admin -> Users tab.

2. Access the user's profile​

Search for the user in the list, and click on it to access their profile.

3. Click on Associated VaultysID​

From the user's profile, select the Associated VaultysID tab.

4. Click on Add​

The different identities of the user will appear. Click on the Add button to start the process of pairing a new identity.

5. Options​

You can send an email to the user to register later. If the user is with you, choose the QR Code option.

6. Pairing​

The user can then scan the QR code displayed on the screen to pair their new device.

7. Set as default​

The new identity will then appear in the list. Set it as default by clicking on the yellow star.

8. Delete the lost identity​

For security reasons, delete the lost identity by clicking on the red trash can.

Rename the identity (optional)​

9. Click on edit​

You can rename the new identity for easier management. To do this, click on the blue pencil.

10. Rename​

Enter a name for the identity, for example, the smartphone model to easily understand which device this identity corresponds to.

Click on Save to save the new name.
