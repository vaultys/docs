Définir un mot de passe commun

Pour chaque application, il est possible de définir des mots de passe communs à plusieurs personnes.

Pour cela, il suffit de partager l'application avec un dossier et de définir un mot de passe pour ce dossier.

Ainsi, toutes les personnes autorisées dans ce dossier auront accès au mot de passe de l'application.

1. Cliquez sur l'onglet Applications​

2. Page de configuration​

Pour accéder à la page de configuration avancée d'une application, recherchez votre application dans la liste et cliquez dessus.

3. Partager​

Cliquez sur l'onglet "Partager" pour accéder aux configurations de partages de l'application.

4. Créer un mot de passe​

Si votre application est partagée avec des dossiers, vous pouvez choisir un dossier et définir un mot de passe pour chacun d'eux.

Vous pouvez alors définir un nom d'utilisateur et un mot de passe.

En activant la "Vérification en deux étapes" (2FA), vous pouvez également entrer la clé secrète correspondante (cette clé secrète peut être récupérée généralement dans les paramètres de l'application elle-même).

Vous pouvez également ajouter des notes sécurisées.

Cliquez sur le bouton "Enregistrer" pour confirmer.
