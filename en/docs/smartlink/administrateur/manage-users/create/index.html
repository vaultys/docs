Créer des utilisateurs

2. Page utilisateurs​

Cliquez sur l'onglet Utilisateurs pour accéder à la page Utilisateurs.

2. Page d'ajout des utilisateurs​

Cliquez sur le bouton Ajouter pour accéder à la page d'ajout d'utilisateurs.

Ajout manuel​

3. Option ajout manuel​

Cliquez sur l'option Manuel pour ajouter des utilisateurs manuellement.

4. Coordonnées de l'utilisateur​

Entrez l'email, le prénom et le nom de votre utilisateur. Le numéro de téléphone est optionnel.

5. Administrateur​

Cliquez sur le switch Administrateur si vous souhaitez attribuer les droits administrateurs à cet utilisateur.

6. Partager des dossiers​

Vous pouvez directement définir les dossiers auxquels cet utilisateur aura accès. Pour cela, cliquez sur la barre de recherche, recherchez un dossier et cliquez dessus pour l'ajouter. Si vous entrez le nom d'un dossier qui n'existe pas, vous avez la possibilité d'en créer un nouveau.

7. Valider l'utilisateur​

Cliquez sur le bouton Enregistrer pour valider l'utilisateur. Il sera alors ajouté à votre liste d'utilisateurs en cours.

Importer​

8. Ajout via un fichier CSV​

Vous pouvez importer une liste d'utilisateurs directement via un fichier CSV. Pour cela, choisissez l'option Importer.

9. Exemple​

Cliquez pour télécharger un exemple de fichier CSV. Remplissez ce fichier avec vos propres données.

10. Importer​

Pour importer un fichier, cliquez sur le bouton Importer et sélectionnez votre fichier. Les utilisateurs seront alors ajoutés à votre liste d'utilisateurs en cours.

Valider​

⚠️ Confirmer la liste d'utilisateurs​

À ce stade, vos utilisateurs n'ont pas été ajoutés au SmartLink, mais dans une file d'attente que vous pouvez consulter et valider pour les ajouter au SmartLink.

11. Accéder à la liste​

Cliquez sur le bouton pour accéder à la liste d'utilisateurs en cours de création.

12. Confirmer​

La liste des utilisateurs prêts à être créés s'affiche. Vérifiez les informations. Vous pouvez éventuellement éditer les partages de dossiers ou supprimer des utilisateurs.

Cliquez sur Confirmer pour ajouter les utilisateurs à votre SmartLink.
