🔐 Gestionnaire de mot de passe

1. Cliquez sur l'onglet Mots De Passe​

L'onglet Mots De Passe vous permet d'accéder à votre gestionnaire de mots de passe.

Vous y trouvez toutes vos applications sur lesquelles vous pouvez définir ou accéder à des mots de passe.

2. Cliquez sur une application​

3. Mot de passe personnel​

Une application peut appartenir à plusieurs dossiers, et chaque dossier peut avoir un mot de passe qui lui est propre.
En tant qu'utilisateur vous pouvez définir un mot de passe auquel vous serez le seul à avoir accès, en choisissant le dossier Personnel.

4. Copier le mot de passe​

Maintenant qu'un mot de passe est définit, vous pouvez à tout moment venir le récupérer. Pour cela cliquez sur les boutons "Copier le nom d'utilisateur", "Copier le mot de passe" ou encore "Afficher les notes sécurisées"

5. Mot de passe de dossier​

Vous pouvez également obtenir le mot de passe des dossiers auxquels vous avez accès.
