Plusieurs identités Vaultys peuvent être associées à votre compte SmartLink. Vous pouvez les retrouver dans votre Profil. Une identité est représentée par une suite de nombre et de lettres, mais il est possible de modifier leurs noms pour que cela soit plus explicite pour vous.
