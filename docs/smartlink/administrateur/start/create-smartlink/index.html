Créer son SmartLink

1. Rendez-vous sur go.vaultys.com/smartlink​

Pour créer votre SmartLink rendez-vous sur https://go.vaultys.com/smartlink .

Vous serez guidez pas à pas pour créer votre identité VaultysID et votre SmartLink.

2. Créez votre VaultysID​

VaultysID id, votre identité numérique décentralisée, peut être installée sur votre smartphone (recommandé) ou sur votre ordinateur, dans votre navigateur web.

Installer VaultysID sur smartphone​

Pour installer VaultysID sur votre smartphone, scannez le QR code avec l'appareil photo de votre téléphone. Vous serez redirigé vers la page de téléchargement de l'application VaultysID.

Puis cliquez sur "Suivant" pour continuer la création de votre SmartLink.

Installer VaultysID dans le navigateur web​

Si vous préférez installer VaultysID dans votre navigateur web, cliquez sur l'onglet "Alternative". Cliquez ensuite sur le bouton "Ouvrir dans le navigateur", ou rendez-vous sur https://wallet.vaultys.net, pour créer votre identité VaultysID directement dans votre navigateur web.

Puis revenez sur l'onglet go.vaultys.com et cliquez sur "Suivant" pour continuer la création de votre SmartLink.

3. Testez votre identité décentralisée VaultysID​

Tester VaultysID sur smartphone​

Si vous avez installé VaultysID sur votre smartphone, ouvrez l'application VaultysID et cliquez sur le bouton de scan QR code. Puis scannez le QR code affiché sur la page go.vaultys.com.

Tester VaultysID dans le navigateur web​

Si vous avez installé VaultysID dans votre navigateur web, cliquez sur le bouton "Ouvrir VaultysID dans le navigateur". Un nouvel onglet s'ouvre sur votre identité VaultysID, cliquez sur votre profil pour vous authentifier avec.

4. Création de votre SmartLink​

Vous êtes maintenant authentifié sur go.vaultys.com avec votre identité décentralisée VaultysID, félicitations !

Remplissez le formulaire de création de SmartLink​

Il ne vous reste plus qu'à créer votre SmartLink en remplissant le formulaire.

Vérifiez votre adresse email​

Un email de vérification vous est envoyé pour vérifier votre adresse email. Entrez le code de vérification reçu par email ici :

Vous serez ensuite redirigé vers votre SmartLink fraîchement créé !
