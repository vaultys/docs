Gestion des licences

SmartLink vous aide à analyser vos licences actives et coûts par application pour une meilleure maîtrise budgétaire.

Pour cela vous pouvez définir pour chaque application le prix d'une licence, et laisser SmartLink estimez vos coûts totaux en fonction du nombre d'utilisateur ayant accès à cette application.

Définir la licence​

Entrez 0 utilisateurs pour que SmartLink estime lui même le nombre de licence. Pour cela, il s'appuira sur :

  • Le nombre de compte qui existent réelement dans l'application. Cela est possible uniquement si l'interface SCIM est configurée (onglet Provisioning).
  • Le nombre d'utilisateur SmartLink qui ont accès à l'application, directement ou via un dossier.
