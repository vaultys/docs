Gérer les applications

Ce guide explique comment utiliser la page de gestion des applications dans SmartLink.

Vue d'ensemble​

Depuis l'onglet Applications, vous avez accès à la liste complète de vos applications avec leurs informations d'accès et de provisionnement.

Recherche d'une application​

Utilisez la barre de recherche pour retrouver rapidement une application par son nom ou son URL.

Filtrer par type​

Cliquez sur le bouton Type pour filtrer les applications par type : Password Manager, SAML ou OpenID.

Filtrer par provisionnement​

Cliquez sur le bouton Provisioning pour filtrer les applications selon leur mode de provisionnement (aucun ou SCIM).

Actions sur une application​

Cliquez sur le menu d'actions (⋮) d'une application pour accéder aux actions disponibles : Partager, Modifier ou Supprimer.

Pagination​

Naviguez entre les pages pour parcourir l'ensemble de vos applications.

Ajustez le nombre d'applications affichées par page grâce au sélecteur en bas de la liste.
