Shadow IT

Shadow IT ?​

Le Shadow IT désigne l'utilisation de logiciels, d'applications ou de services informatiques au sein d'une entreprise sans l'approbation ou le contrôle du service informatique. Il peut s'agir d'outils cloud, de solutions de stockage, de messageries ou même d'applications développées en interne par des employés pour répondre à des besoins spécifiques. Bien que cela puisse améliorer la productivité et l'innovation, le Shadow IT pose des risques en matière de sécurité, de conformité et de gestion des données, car ces solutions échappent aux politiques et aux protections mises en place par l'entreprise.

Par le biais de son Extension pour navigateur, SmartLink est capable de détecter le Shadow IT au sein de votre entreprise.

Accéder au Shadow IT de mon entreprise​

L'onglet Shadow IT vous permet de visualiser toutes les applications non autorisées détectées par l'extension SmartLink.

Filtres​

Vous disposez de plusieurs filtres pour organiser l'affichage des applications Shadow IT :

  • Traité : Affiche les applications Shadow IT qui ont déjà été traitées

  • Ignoré : Affiche les applications qui ont été marquées comme ignorées

Actions​

Pour chaque application Shadow IT détectée, vous pouvez effectuer différentes actions via le menu dédié :

Vous pouvez effectuer plusieurs actions sur une application Shadow IT :

  • Ajouter aux applications : Permet de créer une application SmartLink à partir de ce Shadow IT. Cela fait passer l'application Shadow au statut "Traité", et l'application sera donc autorisée par votre SmartLink. N'oubliez pas de configurer les partages de la nouvelle application SmartLink, pour qu'elle soit visible par vos utilisateurs.
  • Créer un ticket : Permet de créer un Ticket pour suivre plus tard depuis l'onglet Messages.
  • Blacklister l'app : Permet d'ajouter cette application dans votre Blacklist. La blacklist permet de bloquer totalement l'accès à un domaine par vos utilisateurs.
  • Ignorer : Permet d'ignorer totalement les prochains événements relatifs à cette app. Vous ne saurez plus si cette application est utilisée par vos utilisateurs. Cela revient à approuver cette application, sans l'ajouter à SmartLink.

Onglet Événements​

L'onglet Événements affiche l'historique des actions détectées pour cette application :

Vous retrouvez dans cet onglet les formulaires qui ont été bloqués par l'extension, ainsi que les connexions qui ont eu lieu sur cette application.

Pour chaque événement, vous pouvez :

  • Ajouter en tant qu'URL de connexion : Ajoute le lien affiché dans l'événement dans la configuration d'une application SmartLink existante pour éviter que ce genre d'événement soit remonté à l'avenir. Il arrive souvent qu'une application ait plusieurs domaines pour la connexion. Cette option vous permet de gérer ce genre de cas.
  • Supprimer : Supprime l'événement de l'historique.
