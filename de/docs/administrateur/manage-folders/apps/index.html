Apps zuweisen

1. Zugriff auf das Administrations-Dashboard​

Klicken Sie oben rechts auf SmartLink und dann auf den Administrator-Modus, um auf das Administrations-Dashboard zuzugreifen.

2. Klicken Sie auf Gruppen​

Über das Kontextmenü​

3. Klicken Sie mit der rechten Maustaste auf den Ordner​

Sie können die Apps eines Ordners konfigurieren, indem Sie mit der rechten Maustaste darauf klicken und dann auf "Apps konfigurieren" klicken.

4. Wählen Sie die Apps aus​

Ein Fenster mit zwei Spalten wird geöffnet. Die linke Spalte enthält die Liste der Apps im Ordner. Die rechte Spalte enthält die anderen Apps von SmartLink. Klicken Sie auf eine App, um sie dem Ordner hinzuzufügen/zu entfernen.

Über die Übersicht​

5. Klicken Sie auf einen Ordner​

Klicken Sie auf einen Ordner, um die Übersicht des Ordners auf der rechten Seite anzuzeigen.

6. Wählen Sie die Apps aus​

Klicken Sie auf das erste Symbol (Apps konfigurieren). Das Fenster zur Auswahl der Apps wird erneut geöffnet.

Über die Konfigurationsseite​

7. Zugriff auf die Konfigurationsseite​

Um auf die Konfigurationsseite des Ordners zuzugreifen, klicken Sie darauf, dann auf das Zahnrad-Symbol (Gruppe konfigurieren) oder klicken Sie mit der rechten Maustaste und wählen Sie "Konfigurieren".

8. Klicken Sie auf Apps​

Der Reiter "Apps" ermöglicht die Verwaltung der Apps eines Ordners. Klicken Sie auf "Apps", um darauf zuzugreifen.

9. Wählen Sie die Apps aus​

Klicken Sie dann auf die Schaltfläche "Apps aktualisieren". Das Fenster zur Auswahl der Apps wird erneut geöffnet.
