Lizenzverwaltung

SmartLink hilft Ihnen dabei, Ihre aktiven Lizenzen und Kosten pro Anwendung zu analysieren, um ein besseres Budgetmanagement zu ermöglichen.

Dazu können Sie für jede Anwendung den Preis einer Lizenz festlegen und SmartLink die Gesamtkosten basierend auf der Anzahl der Benutzer, die Zugriff auf diese Anwendung haben, schätzen lassen.

Lizenz festlegen​

Geben Sie 0 Benutzer ein, damit SmartLink die Anzahl der Lizenzen selbst schätzt. Dazu wird es sich auf Folgendes stützen:

  • Die Anzahl der tatsächlich vorhandenen Konten in der Anwendung. Dies ist nur möglich, wenn die SCIM-Schnittstelle konfiguriert ist (Registerkarte Bereitstellung).
  • Die Anzahl der SmartLink-Benutzer, die direkt oder über einen Ordner auf die Anwendung zugreifen.
