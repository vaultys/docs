Anwendung teilen

1. Klicken Sie auf Anwendungen​

Öffnen Sie die Anwendungsverwaltungsseite, indem Sie auf das Admin -> Anwendungen-Registerkarte klicken.

2. App konfigurieren​

3. Teilen-Registerkarte​

4. Teilen​

Sie können eine Anwendung mit Ordnern und/oder Benutzern teilen. Das Teilen mit einem Ordner bedeutet, dass alle Benutzer, die Zugriff auf diesen Ordner haben, Zugriff auf diese Anwendung haben. Wenn es sich um einen gemeinsamen Ordner handelt (Ordner, auf den alle Benutzer zugreifen können), haben alle Benutzer Zugriff auf die Anwendung. Das direkte Teilen mit einem Benutzer ermöglicht es, jemandem den Zugriff zu geben, ohne über einen Ordner zu gehen: Direkter Zugriff.
