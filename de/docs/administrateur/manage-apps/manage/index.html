Gérer les applications

1. Cliquez sur l'onglet Applications​

2. Rechercher​

Utilisez la barre de recherche pour rechercher une application via son nom, URL ou description.

3. Partager​

Cliquez sur le bouton "Partager" pour partager une application avec des dossiers ou des utilisateurs.

4. Plus d'actions​

Cliquez sur le bouton actions pour afficher plus d'options.
