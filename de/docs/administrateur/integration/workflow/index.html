API und Webhooks

Sie können SmartLink mit jeder Software (LDAP, SOC, Google Suite, ...) über die SmartLink API und Webhooks integrieren!

Diese Funktionen sind nur für Platinum- und Enterprise-Lizenzen verfügbar!

Die SmartLink API ermöglicht es Ihnen, Anfragen an Ihren SmartLink zu senden (z.B. Apps abrufen, Benutzer erstellen, ...) für Ihre Integrationen.

Webhooks ermöglichen es, Daten an die von Ihnen gewählte URL zu senden, wenn Ereignisse ausgelöst werden (z.B. Benutzererstellung, Benutzeranmeldung, ...)

Webhooks​

1. Zugriff auf die Administrationskonsole​

Klicken Sie oben rechts in SmartLink auf das Menü und dann auf den Administrator-Modus, um auf die Administrationskonsole zuzugreifen.

2. Klicken Sie auf den Workflow-Tab​

3. Webhooks-Tab​

Im Workflow-Menü stehen zwei Registerkarten zur Verfügung: Webhooks und API

4. Webhooks-Dokumentation​

Klicken Sie auf den Link am Ende der Seite, um auf die Dokumentation zu Webhooks zuzugreifen.

Dort finden Sie eine Liste der verfügbaren Webhooks, Informationen über die enthaltenen Daten und wie Sie sie überprüfen können.

5. Webhook hinzufügen​

Um einen Endpunkt hinzuzufügen (URL, an die Webhooks gesendet werden sollen), klicken Sie auf die Schaltfläche "Endpunkt hinzufügen".

6. Konfigurieren Sie Ihren Webhook​

Fügen Sie die URL hinzu, an die Ihre Webhooks gesendet werden sollen, wählen Sie die Ereignisse aus, die Sie senden möchten, und klicken Sie dann auf "Endpunkt hinzufügen".

SmartLink API​

7. Aktivieren Sie die API​

Die API ist standardmäßig deaktiviert. Klicken Sie auf den Schalter, um die API zu aktivieren.

Ein API-Schlüssel wird generiert. Bewahren Sie diesen Schlüssel vertraulich auf.

8. API-Dokumentation​

Sie können auf die API-Dokumentation zugreifen, indem Sie am Ende der Seite auf den Link klicken.

9. Dokumentation​

Dort finden Sie eine Liste der verfügbaren Anfragen.

Sie können auch jede Anfrage direkt über die SmartLink-Benutzeroberfläche testen, ohne den API-Schlüssel angeben zu müssen (die Authentifizierung erfolgt über Ihre Sitzung auf SmartLink).
