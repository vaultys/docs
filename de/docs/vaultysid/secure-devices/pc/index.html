Sécuriser son PC et configurer les passkeys

🔒 1. Principes de base pour sécuriser son PC​

Un PC sécurisé est un PC protégé contre les cyberattaques, les virus et les intrusions. Voici les bases pour sécuriser votre ordinateur.

✅ 1.1 Mettre à jour son système d'exploitation​

  • Windows : Paramètres > Mise à jour et sécurité > Windows Update
  • macOS : Préférences Système > Mise à jour de logiciels
  • Linux : Utiliser les commandes :
    • Ubuntu/Debian : sudo apt update && sudo apt upgrade
    • Fedora : sudo dnf update

📖 Guide Microsoft - Windows Update
📖 Guide Apple - Mise à jour macOS

🔐 1.2 Activer un antivirus et un pare-feu​

  • Windows : Sécurité Windows > Protection contre les virus et menaces
  • macOS : Pare-feu activé dans Sécurité et confidentialité
  • Linux : Installer ufw (sudo apt install ufw), puis activer avec sudo ufw enable

📖 Guide Microsoft - Sécurité Windows

📖 Guide Google Chrome - Sécuriser votre navigation

📖 Guide Apple Safari - Confidentialité et Sécurité

🔏 1.3 Utiliser SmartLink​

Bonne nouvelle pour vous, en utilisant SmartLink vous faites déjà un pas de géant vers la sécurisation de votre environnement IT !

🕵️ 1.4 Sécuriser son navigateur et ses connexions​

  • Activer HTTPS Everywhere et bloquer les cookies tiers
  • Vérifier les autorisations des extensions
  • Utiliser un VPN si vous êtes sur un Wi-Fi public
  • Mettez régulièrement à jour votre navigateur

📖 Guide Google - Sécuriser Chrome

🔑 2. Configurer les passkeys sur PC​

Les passkeys sont des alternatives sécurisées aux mots de passe, compatibles avec Windows Hello, macOS Touch ID et FIDO2.

🖥️ 2.1 Activer Windows Hello sur Windows 10/11​

  1. Paramètres > Comptes > Options de connexion
  2. Sous Windows Hello, configurez la reconnaissance faciale, l’empreinte digitale ou un code PIN
  3. Assurez-vous que votre compte Microsoft est synchronisé

📖 Guide Windows Hello - Microsoft

🍏 2.2 Activer les passkeys sur macOS​

  1. Préférences Système > Mots de passe
  2. Cliquez sur un compte compatible et sélectionnez Ajouter une passkey
  3. Confirmez avec Touch ID ou mot de passe d’administrateur

📖 Guide Passkeys sur macOS

🔐 2.3 Utiliser une clé de sécurité FIDO2​

Si votre PC ne supporte pas Windows Hello ou Touch ID, vous pouvez utiliser une clé de sécurité USB/NFC :

  • YubiKey : Compatible Windows/macOS/Linux
  • Google Titan : Compatible services Google

📖 YubiKey - Clés de sécurité FIDO2
📖 Google Titan - Clé de sécurité

✅ Conclusion​

En suivant ces étapes, votre PC sera protégé contre la plupart des menaces. La configuration des passkeys simplifie l’authentification tout en renforçant votre sécurité. 🚀🔒
