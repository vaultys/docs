🔌 Verbinden

Wenn Sie auf SmartLink zugreifen, werden Sie automatisch zur Anmeldeseite weitergeleitet, wenn Sie nicht bereits angemeldet sind.

1. Klicken Sie auf Anmelden​

Klicken Sie auf die Schaltfläche Anmelden, um den Anmeldevorgang zu starten und den QR-Code anzuzeigen.

2. Scannen Sie den QR-Code​

Öffnen Sie die VaultysID-App auf Ihrem Smartphone und scannen Sie den QR-Code, der auf dem Bildschirm Ihres PCs angezeigt wird, um sich anzumelden.

3. Genießen Sie SmartLink!​
