🖥️ Den PC sichern und Passkeys konfigurieren

🔒 1. Grundprinzipien zur Sicherung Ihres PCs​

Ein sicherer PC ist ein PC, der vor Cyberangriffen, Viren und Eindringlingen geschützt ist. Hier sind die Grundlagen, um Ihren Computer zu sichern.

✅ 1.1 Aktualisieren des Betriebssystems​

  • Windows: Einstellungen > Update und Sicherheit > Windows Update
  • macOS: Systemeinstellungen > Softwareupdate
  • Linux: Verwenden Sie die Befehle:
    • Ubuntu/Debian: sudo apt update && sudo apt upgrade
    • Fedora: sudo dnf update

📖 Microsoft-Leitfaden - Windows Update
📖 Apple-Leitfaden - macOS-Update

🔐 1.2 Aktivieren eines Antivirus-Programms und einer Firewall​

  • Windows: Windows-Sicherheit > Schutz vor Viren und Bedrohungen
  • macOS: Firewall aktivieren unter Sicherheit und Datenschutz
  • Linux: Installieren Sie ufw (sudo apt install ufw) und aktivieren Sie es mit sudo ufw enable

🔏 1.3 SmartLink verwenden​

Eine gute Nachricht für Sie, wenn Sie SmartLink verwenden, machen Sie bereits einen großen Schritt zur Sicherung Ihrer IT-Umgebung!

🕵️ 1.4 Den Browser und die Verbindungen sichern​

  • Aktivieren Sie HTTPS Everywhere und blockieren Sie Drittanbieter-Cookies
  • Überprüfen Sie die Berechtigungen von Erweiterungen
  • Verwenden Sie ein VPN, wenn Sie sich in einem öffentlichen WLAN befinden
  • Aktualisieren Sie regelmäßig Ihren Browser

🔑 2. Konfigurieren der Passkeys auf dem PC​

Passkeys sind sichere Alternativen zu Passwörtern, die mit Windows Hello, macOS Touch ID und FIDO2 kompatibel sind.

🖥️ 2.1 Windows Hello auf Windows 10/11 aktivieren​

  1. Einstellungen > Konten > Anmeldeoptionen
  2. Unter Windows Hello konfigurieren Sie Gesichtserkennung, Fingerabdruck oder eine PIN
  3. Stellen Sie sicher, dass Ihr Microsoft-Konto synchronisiert ist

📖 Windows Hello-Leitfaden - Microsoft

🍏 2.2 Passkeys auf macOS aktivieren​

  1. Systemeinstellungen > Passwörter
  2. Klicken Sie auf ein kompatibles Konto und wählen Sie Passkey hinzufügen
  3. Bestätigen Sie mit Touch ID oder Administratorpasswort

📖 Leitfaden zu Passkeys auf macOS

🔐 2.3 Verwenden eines FIDO2-Sicherheitsschlüssels​

Wenn Ihr PC Windows Hello oder Touch ID nicht unterstützt, können Sie einen USB/NFC-Sicherheitsschlüssel verwenden:

  • YubiKey: Kompatibel mit Windows/macOS/Linux
  • Google Titan: Kompatibel mit Google-Diensten

📖 YubiKey - FIDO2-Sicherheitsschlüssel
📖 Google Titan - Sicherheitsschlüssel

✅ Fazit​

Indem Sie diesen Schritten folgen, wird Ihr PC vor den meisten Bedrohungen geschützt sein. Die Konfiguration der Passkeys vereinfacht die Authentifizierung und stärkt gleichzeitig Ihre Sicherheit. 🚀🔒
