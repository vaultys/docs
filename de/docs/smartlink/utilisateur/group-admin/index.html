Administrateur de dossier

En tant qu'administrateur de dossier, vous pouvez gérer les utilisateurs, les applications et la sécurité des dossiers qui vous ont été délégués. Vos actions disponibles dépendent des droits accordés par un administrateur global.

Info

Les droits possibles sont les suivants :

  • Gérer les mots de passe — Toujours disponible, même sans droits supplémentaires.
  • Sélectionner les admins — Permet de voir l'onglet Utilisateurs et de désigner les responsables du dossier, et de définir leurs droits.
  • Modifier les applications — Permet de modifier les applications existantes du dossier.
  • Créer des applications — Permet d'ajouter de nouvelles applications au dossier.
  • Renommer le dossier — Permet de modifier le nom du dossier.

Vue d'ensemble​

La page Administrateur de dossier liste tous les dossiers dont vous êtes responsable.

Cliquez sur un dossier dans la liste de gauche pour afficher son résumé.

Résumé du dossier​

Le panneau de résumé vous donne un aperçu rapide des applications et des membres du dossier.

Cliquez sur Configurer pour accéder à la page de gestion détaillée du dossier.

Page de gestion du dossier​

La page de gestion s'organise en onglets selon vos droits : Utilisateurs, Applications et Sécurité.

Renommer le dossier​

Si vous disposez du droit Renommer le dossier, une icône crayon apparaît à droite du nom. Cliquez dessus pour le modifier.

Info

Ce bouton n'apparaît que si le droit Modifier le dossier vous a été accordé.

Onglet Utilisateurs​

L'onglet Utilisateurs vous permet de gérer les membres du dossier et leurs rôles.

Info

Cet onglet n'est visible que si le droit Modifier les administrateurs vous a été accordé.

Pour chaque utilisateur, vous pouvez modifier son rôle (administrateur ou non) et ses droits d'accès.

Onglet Applications​

L'onglet Applications liste les applications présentes dans le dossier.

Créer une application​

Si vous disposez du droit Créer des applications, un bouton de création est disponible dans la barre d'outils.

Info

Ce bouton n'apparaît que si le droit Créer des applications vous a été accordé.

Modifier une application​

Si vous disposez du droit Modifier des applications, chaque application dispose d'un bouton de modification.

Info

Cette action n'est disponible qu'avec le droit Modifier des applications.

Onglet Sécurité​

L'onglet Sécurité vous permet de consulter et gérer les mots de passe liés aux applications du dossier.
