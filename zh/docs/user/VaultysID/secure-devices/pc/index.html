🖥️ 安全配置您的计算机并设置通行证

🔒 1. 安全配置计算机的基本原则​

一个安全的计算机是受到保护免受网络攻击、病毒和入侵的计算机。以下是保护您的计算机的基本方法。

✅ 1.1 更新操作系统​

  • Windows：设置 > 更新和安全 > Windows 更新
  • macOS：系统偏好设置 > 软件更新
  • Linux：使用以下命令：
    • Ubuntu/Debian：sudo apt update && sudo apt upgrade
    • Fedora：sudo dnf update

📖 微软指南 - Windows 更新
📖 苹果指南 - macOS 更新

🔐 1.2 启用防病毒软件和防火墙​

  • Windows：Windows 安全 > 病毒和威胁防护
  • macOS：在安全性与隐私中启用防火墙
  • Linux：安装ufw（sudo apt install ufw），然后使用sudo ufw enable启用

📖 微软指南 - Windows 安全

📖 谷歌 Chrome指南 - 保护您的浏览器

📖 苹果 Safari指南 - 隐私与安全

如果您希望我直接将它们添加到文档中，请告诉我！ 😊

🔏 1.3 使用 SmartLink​

对您来说是个好消息，使用 SmartLink 已经让您迈出了保护您的 IT 环境的重要一步！

🕵️ 1.4 安全配置浏览器和连接​

  • 启用HTTPS Everywhere并阻止第三方 Cookie
  • 检查扩展程序的权限
  • 如果您使用公共 Wi-Fi，请使用 VPN
  • 定期更新您的浏览器

📖 Mozilla指南 - 保护 Firefox
📖 谷歌指南 - 保护 Chrome
📖 苹果指南 - 保护 Safari

🔑 2. 在计算机上配置通行证​

通行证是密码的安全替代方案，与Windows Hello、macOS Touch ID 和 FIDO2兼容。

🖥️ 2.1 在 Windows 10/11 上启用 Windows Hello​

  1. 设置 > 帐户 > 登录选项
  2. 在Windows Hello下，配置面部识别、指纹或 PIN 码
  3. 确保您的 Microsoft 帐户已同步

📖 Windows Hello指南 - 微软

🍏 2.2 在 macOS 上启用通行证​

  1. 系统偏好设置 > 密码
  2. 单击兼容帐户并选择添加通行证
  3. 使用Touch ID或管理员密码进行确认

📖 macOS上通行证指南

🔐 2.3 使用 FIDO2 安全密钥​

如果您的计算机不支持 Windows Hello 或 Touch ID，您可以使用 USB/NFC 安全密钥：

  • YubiKey：兼容 Windows/macOS/Linux
  • Google Titan：兼容 Google 服务

📖 YubiKey - FIDO2 安全密钥
📖 Google Titan - 安全密钥

✅ 结论​

通过遵循这些步骤，您的计算机将受到大多数威胁的保护。配置通行证简化了身份验证过程，同时增强了您的安全性。 🚀🔒
