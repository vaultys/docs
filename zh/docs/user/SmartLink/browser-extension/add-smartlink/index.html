➕ 添加一个智能链接

1. 打开菜单​

单击右上角的按钮以打开菜单。

2. 点击添加新的智能链接​

3. 输入URL​

您将进入智能链接添加屏幕。在相应的字段中输入您的智能链接的URL（例如：https://mon-smartlink.link.vaultys.org）。

4. 点击添加​

扩展将尝试将您的智能链接连接到您指定的URL。如果URL正确，您的智能链接将被添加（根据网络状态可能需要几秒钟）。 单击“添加”开始验证。

5. 登录​

您将进入登录页面，请单击“连接”以登录到新的智能链接。

6. 在您的智能链接之间导航​

打开菜单后，您将看到您的智能链接列表。单击其中一个以切换当前的智能链接。
