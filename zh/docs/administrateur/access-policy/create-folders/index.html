创建您的文件夹

1. 点击访问策略​

2. 添加文件夹​

3. 操作​

单击操作按钮以执行更多操作。

您可以：

  • 克隆文件夹：创建一个新文件夹，并有可能复制用户和/或应用程序。
  • 添加子文件夹
  • 修改文件夹名称
  • 删除文件夹

4. 配置​

在这个选项卡中，您可以修改文件夹名称，或将其设置为共享文件夹。共享文件夹将对所有用户可见。非常适用于共享常用应用程序，例如电子邮件。

在这里，管理文件夹的用户。确定要与谁共享此文件夹，并可能为某些用户在此文件夹上设置管理权限。

此选项卡允许您确定要与此文件夹共享哪些应用程序。请记住，所有访问此文件夹的用户都将访问此应用程序列表。
