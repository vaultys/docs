API和Webhooks

您可以通过SmartLink的API和Webhooks与任何软件集成（如LDAP、SOC、Google Suite等）！

这些功能仅适用于Platinum和Enterprise许可证！

SmartLink API允许您向您的SmartLink发出请求（例如：获取应用程序、创建用户等）以进行集成。

Webhooks允许在触发事件时将数据发送到您选择的URL（例如：创建用户、用户登录等）。

Webhooks​

1. Configuration Tab​

2. Click on Webhooks Tab​

3. Webhooks Documentation​

单击页面底部的链接以访问有关Webhooks的文档

您将找到可用的Webhooks列表、它们包含的数据信息以及验证方法。

4. Add a Webhook​

要添加一个端点（将发送Webhooks的URL），请单击“添加端点”按钮

5. Configure Your Webhook​

添加将发送Webhooks的URL，选择要发送的事件，然后单击“添加端点”。

SmartLink API​

6. Click on API Tab​

7. Enable the API​

API默认处于禁用状态。单击开关以启用API。

将生成一个API密钥，请保密此密钥。

8. API Documentation​

您可以单击页面底部的链接访问API文档

9. Documentation​

然后您将找到可用请求的列表。

您还可以直接从SmartLink界面测试每个请求，无需填写API密钥（身份验证通过您在SmartLink上的会话完成）
