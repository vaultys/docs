进度​

该选项卡专为帮助您开始使用 SmartLink 而设计。我们将引导您完成添加首个用户、应用程序、文件夹等不同步骤！

2. 设置​

9. 组织​

点击“组织”选项卡。

10. 组织设置​

在这里，您可以修改 SmartLink 的全局设置，如默认语言或用户会话时长。

Webhooks​

💡 通过 Webhooks 进行集成​

Webhooks 允许您在事件发生后将信息发送到您选择的端点（例如，创建用户）。

这有助于与其他应用程序集成。

12. Webhooks 选项卡​

点击“Webhooks”选项卡。

了解更多关于 Webhooks

API​

💡 通过 API 进行集成​

与 Webhooks 一样，API 有助于与其他应用程序集成。通过启用 API，您可以从外部向 SmartLink 发送请求。

13. API 选项卡​

点击“API”选项卡以访问 API 配置。

了解更多关于 API
