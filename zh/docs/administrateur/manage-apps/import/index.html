Importer des applications

Vous pouvez importer des applications depuis n'importe quel fichier au format CSV. La plupart des gestionnaires de mot de passe proposent une exportation dans ce format.

1. Accédez à la console administration​

Cliquez sur le menu en haut à droite de SmartLink puis sur Mode administrateur pour accéder à la console administration

2. Cliquez sur Applications​

Accédez à la page de gestion des applications en cliquant sur l'onglet Admin -> Applications.

3. Cliquez sur Importer des applications​

4. Cliquez sur Importer​

Cliquez sur Importer pour ouvrir l'explorateur de fichiers, et sélectionnez le fichier que vous voulez importer.

5. Liez les champs​

Les différentes colonnes du fichier seront détectées. Sélectionnez ensuite l'équivalence SmartLink de chaque champ que vous voulez importer.
Par exemple, si le fichier contient un champ "password", cliquez sur le menu déroulant à droite et choisissez "Mot de Passe".

6. Cliquez sur Suivant​

7. Sélectionnez les applications à importer​

La liste des applications que vous êtes sur le point d'importer s'affiche dans un tableau. Vous pouvez sélectionnez des applications puis cliquer sur le bouton Supprimer pour ne pas importer certaines applications.

8. Cliquez sur Importer​
