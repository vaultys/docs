管理密码

背景​

Émilie 是 WebAgency 的项目经理。她每天使用大约三十个应用程序：公司提供的工具（Jira、GitLab、Slack）、与团队共享的账号（主机、分析工具），以及她的个人工具（LinkedIn、在线学习）。她以前把密码保存在桌面上的一个文本文件里。

没有 SmartLink 的问题​

  • 工作和个人密码混在一起
  • 团队账号通过消息或共享文件传递
  • 共享密码没有任何安全保障
  • 同事离职时，无法知道他掌握了哪些密码
  • 无法追踪所用密码的强度

使用 SmartLink​

第一步 — 导入现有密码​

Émilie 从她之前的密码管理器（或文本文件）导入密码。SmartLink 会自动将它们整理到合适的保险箱中。

第二步 — 三个保险箱，三种用途​

SmartLink 将密码分为三个独立的保险箱：

  • 🏢 企业保险箱：由管理员提供的账号信息。Émilie 可以使用，但不能修改——由 IT 部门管理。
  • 🔒 个人保险箱：Émilie 自己管理的账号信息。只有她本人可以访问，连管理员也无法查看。
  • 🤝 共享保险箱：团队账号信息。Émilie 和同事都可以访问，任何更改都会自动同步。

第三步 — 加强安全性​

SmartLink 会分析每个密码的强度，并在密码较弱、重复使用或被泄露时提醒 Émilie。她可以用自动生成的强密码进行替换。

第四步 — 日常使用​

当 Émilie 访问网站时，浏览器扩展会自动填写来自正确保险箱的账号信息。如果她创建新账号，SmartLink 会建议将其保存到合适的保险箱中。

带来的变化​

没有 SmartLink使用 SmartLink
文本文件或便利贴加密保险箱
工作/个人密码混杂三个独立有序的保险箱
消息方式共享同步的共享保险箱
没有安全提醒检测弱密码

使用的功能​

  • 🔑 密码管理器 — 三个保险箱（企业、个人、共享）
  • 📥 密码导入 — 从其他管理器迁移
  • 🧩 浏览器扩展 — 自动填写表单
