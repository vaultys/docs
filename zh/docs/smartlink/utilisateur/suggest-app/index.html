suggérer une application

Si vous avez besoin d'une nouvelle application mais que vous n'avez pas les droits pour en ajouter, vous pouvez suggérer des applications aux administrateurs. Cela créera aux notification chez tous les administrateurs du SmartLink.

1. Cliquez sur l'onglet Mes Applications​

2. Cliquez sur Suggérer une app aux administrateurs​

3. Suggérez l'application​

Entrez l'URL de l'application dans la fenêtre qui apparaît, puis cliquez sur Suggérer l'app.
