仪表板

仪表板是您进入 SmartLink 的起点。它汇总了您授权的所有应用程序，并允许您通过几次点击打开、组织和管理它们的访问权限。

热门应用和收藏夹​

您的应用程序分为两个选项卡。

热门选项卡​

热门 选项卡显示您最常使用的应用程序，按访问次数排序。这是默认显示的选项卡。

打开应用程序​

单击应用程序以在新标签页中直接打开。如果应用程序配置了由 SmartLink 管理的密码，则会打开密码管理器。

图标大小​

在网格右上角使用 视图 按钮选择图标显示大小。

有三种大小可供选择：小、中或大。您的偏好会自动保存。

搜索应用程序​

搜索栏会随着输入实时过滤所有应用程序。

从搜索中添加到收藏夹​

将鼠标悬停在搜索结果上，以显示星形图标按钮，然后单击该按钮将应用程序添加到收藏夹。

收藏夹选项卡​

收藏夹 选项卡包含您标记为收藏的应用程序。显示的计数器显示活动收藏夹的数量。

从网格中管理收藏夹​

将鼠标悬停在网格中的应用程序上，以显示其操作：分享链接、添加或移除收藏夹，以及管理密码。单击星形图标切换应用程序的收藏状态。
