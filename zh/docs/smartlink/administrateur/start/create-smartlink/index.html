创建您的SmartLink

1. 前往 go.vaultys.com/smartlink​

要创建您的SmartLink，请访问 https://go.vaultys.com/smartlink。

您将逐步创建您的VaultysID身份和SmartLink。

2. 创建您的VaultysID​

VaultysID，您的分散式数字身份，可安装在您的智能手机（推荐）或计算机上，即在您的网络浏览器中。

在智能手机上安装VaultysID​

要在您的智能手机上安装VaultysID，请使用手机的摄像头扫描QR码。 然后您将被重定向到VaultysID应用程序的下载页面。

然后点击“下一步”以继续创建您的SmartLink。

在网络浏览器中安装VaultysID​

如果您更喜欢在网络浏览器中安装VaultysID，请点击“替代”选项卡。 然后点击“在浏览器中打开”，或者访问 https://wallet.vaultys.net，在您的网络浏览器中直接创建您的VaultysID身份。

然后返回到 go.vaultys.com 选项卡，点击“下一步”以继续创建您的SmartLink。

3. 测试您的分散式身份VaultysID​

在智能手机上测试VaultysID​

如果您已在智能手机上安装了VaultysID，请打开VaultysID应用并点击扫描QR码按钮。 然后扫描显示在 go.vaultys.com 页面上的QR码。

在网络浏览器中测试VaultysID​

如果您已在网络浏览器中安装了VaultysID，请点击“在浏览器中打开VaultysID”按钮。 一个新标签页将打开显示您的VaultysID身份，请点击您的个人资料以进行身份验证。

4. 创建您的SmartLink​

恭喜！您现在已经使用您的分散式VaultysID身份在 go.vaultys.com 上进行了身份验证！

填写SmartLink创建表单​

您只需填写表单即可创建您的SmartLink。

验证您的电子邮件地址​

您将收到一封验证电子邮件以验证您的电子邮件地址。 在此处输入通过电子邮件收到的验证代码：

然后您将被重定向到您刚刚创建的SmartLink！
