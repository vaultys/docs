使用 SmartLink 起步

信息

💡 第一次使用 SmartLink，获取所有有用信息的入口

准备您的计算机

要开始使用 SmartLink，您需要在计算机上安装一个更新的浏览器。SmartLink 兼容 Google Chrome、Safari、Firefox。其他类型的浏览器也应该支持 SmartLink，尽管并未进行所有测试。

除了浏览器，您只需要一个互联网连接即可运行 SmartLink。SmartLink 应用程序对带宽要求不高。

在线注册

要注册，请直接访问网站 https://go.vaultys.com，您可以选择演示选项或直接创建免费组织。

演示网站​

如果您直接访问链接 https://start.vaultys.com/demo，请直接填写在线表单。在能够登录到演示环境之前，需要验证您的电子邮件。然后您可以探索应用程序，甚至可以直接从“我的 SmartLink”菜单中创建自己的组织。

免费创建自己的组织​

如果您直接访问链接 https://go.vaultys.com，请直接填写在线表单。在最终注册之前，需要验证您的电子邮件。然后将直接为您提供个性化的网址。这是您访问新 SmartLink 的入口。

首次登录

注册后，您将看到一个特殊页面，解释如何无需密码登录。

然后您需要在您的智能手机上下载 VaultysID 应用程序。这个独立于 SmartLink 的应用程序可让您创建您的身份。有关更多信息，请访问页面 安装 VaultysID

在 SmartLink 中导航​

登录后，您将看到您组织的仪表板。在这里，您可以访问所有信息，管理设置并浏览应用程序的不同部分。请花时间熟悉界面，以便更轻松地使用 SmartLink。

访问用户和管理员菜单

作为 SmartLink 的所有者，您可以访问两种类型的菜单：用户菜单和管理员菜单。

用户菜单​

用户菜单为您提供完整访问 SmartLink 基本功能的权限。您可以在此菜单中访问应用程序，管理密码并根据需要创建新的 SmartLink。

管理员菜单​

如果您拥有管理员权限，还可以访问管理员菜单。该菜单允许您管理 SmartLink 组织的所有方面。您可以添加或删除用户、应用程序或组，并管理组织的设置等。

个人资料菜单​

位于界面右上角的个人资料菜单是您在 SmartLink 上的个人控制中心。通过单击此菜单，您可以访问与您的个人资料相关的一系列信息和设置。

首先，您会找到您的个人设置。这些设置允许您自定义在 SmartLink 上的体验，包括修改个人信息、偏好设置和显示语言。提供的选项有 法语、英语、中文 和 德语。

然后，您有您的登录标识。在这里，您可以管理与您的 SmartLink 帐户相关的所有信息。

最后，您有浏览器扩展管理。此部分允许您添加、修改或删除浏览器中的 SmartLink 扩展。这是一个重要功能，可以让您快速访问您的 SmartLink，而无需每次都打开应用程序。
