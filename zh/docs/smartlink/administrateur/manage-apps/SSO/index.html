SSO

SmartLink est compatible SAML et OpenID Connect. Vous pouvez le configurer pour agir en tant que fournisseur d'identité et accéder à toute vos applications compatibles SAML et OpenID Connect en un clic !

Format des URLs SmartLink​

Les endpoints d'authentification SmartLink suivent ce format :

  • OpenID Connect : https://[votre-smartlink].link.vaultys.org/api/oidc/[appid]/[endpoint]
  • SAML2 : https://[votre-smartlink].link.vaultys.org/api/saml2/[appid]/[endpoint]

Où :

  • [votre-smartlink] est votre sous-domaine SmartLink
  • [appid] est l'identifiant unique de l'application généré automatiquement lors de sa création

Guides d'intégration spécifiques​

SmartLink agit comme un fournisseur d'identité (IdP) et prend en charge les protocoles OpenID Connect et SAML2. Consultez nos guides détaillés pour configurer l'authentification unique avec vos applications :

Guides disponibles​

  • Nextcloud - Plateforme de collaboration cloud avec le plugin Social Login
  • Tailscale - VPN mesh moderne avec support OpenID Connect et WebFinger
  • Headscale - Serveur de contrôle open-source pour Tailscale
  • GitLab - Plateforme DevOps complète (OpenID Connect et SAML2)
  • Grafana - Solution de monitoring et d'observabilité
  • Portainer - Interface de gestion pour conteneurs Docker/Kubernetes

Protocoles supportés​

OpenID Connect​

  • Configuration moderne et simple
  • Support natif dans la plupart des applications cloud
  • Auto-découverte via https://[votre-smartlink].link.vaultys.org/api/oidc/[appid]/.well-known/openid-configuration
  • Support PKCE pour une sécurité renforcée

SAML2​

  • Standard éprouvé pour l'entreprise
  • Compatible avec les applications legacy
  • Métadonnées disponibles à https://[votre-smartlink].link.vaultys.org/api/saml2/[appid]/metadata

Pour plus de détails sur les intégrations disponibles, consultez la liste complète des intégrations SSO.
