添加应用程序

这篇指南将解释如何在 SmartLink 中添加应用程序。

步骤 1：访问应用程序管理​

从管理菜单中，点击应用程序。

步骤 2：打开添加页面​

点击工具栏中的**"添加应用程序"**按钮，进入创建页面。

步骤 3：使用快速搜索栏​

在页面顶部的快速搜索栏中输入 URL 或应用程序名称。

步骤 4：通过 URL 添加应用程序​

输入应用程序的 URL（例如：https://github.com）。SmartLink 将自动获取应用程序信息。

在列表中点击应用程序以将其添加到待办列表中。

步骤 5：无 URL 添加应用程序​

您也可以仅通过名称而不是 URL 添加应用程序。

步骤 6：检查待办列表​

添加的应用程序将显示在待办列表中。在确认之前，您可以继续添加其他应用程序。

步骤 7：确认添加应用程序​

点击**"添加 # 应用程序"**按钮，以创建所有待办应用程序。

步骤 8：确认应用程序已添加​

您将被重定向到应用程序管理页面。新添加的应用程序将显示在列表中。

其他选项：应用商店​

点击应用商店按钮，浏览 SmartLink 应用程序目录，并一键添加。

其他选项：导入​

点击导入按钮，通过 CSV 文件一次性添加多个应用程序。
